# CÉRÉBRON Ω — FARM 59 — VERIFIED LEARNING

Mission: measure whether a change actually improves CÉRÉBRON capability under controlled, reproducible evaluation.

Core loop:
BASELINE -> CHANGE -> SAME BENCHMARK -> BEFORE/AFTER -> ABLATION -> REGRESSION CHECK -> ACCEPT/ROLLBACK

Rules:
- REALITY > COHERENCE
- EVIDENCE > CONFIDENCE
- CLAIM <= EVIDENCE
- MEMORY != LEARNING
- FILE CHANGE != LEARNING
- PROMPT CHANGE != LEARNING
- BENCHMARK GAIN != GENERAL CAPABILITY
- SAME DATA != INDEPENDENT EVIDENCE
- ABLATION BEFORE ADDITION
- VERIFY BEFORE COMMIT
- REGRESSION CHECK BEFORE ACCEPT
- UNKNOWN REMAINS UNKNOWN

Farm 59 does not train a model. Its first executable layer is a deterministic evaluator for paired before/after benchmark records.
